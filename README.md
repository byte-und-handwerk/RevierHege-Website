# RevierHege-Website

Eigenständige Referenz-Landingpage für die iOS-App RevierHege.

## Struktur

- `index.html` – Produkt- und Referenzseite
- `datenschutz.html` – Datenschutzhinweise für die Website
- `app-datenschutz.html` – Datenschutzhinweise für die App
- `impressum.html` – Anbieterkennzeichnung
- `assets/styles.css` – gemeinsames Designsystem
- `assets/site.js` – mobile Navigation und Jahreszahl

Die Seite ist bis zur finalen Domain- und Veröffentlichungsentscheidung bewusst auf `noindex` gesetzt. Vor dem öffentlichen Start müssen Canonical-URL, Sitemap, Robots-Regeln und die final geprüften Rechtstexte ergänzt beziehungsweise freigegeben werden.
